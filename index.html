คู่มือการติดตั้ง Gitea บน AlmaLinux

ระบบติดตั้งแบบ Step-by-Step พร้อมแนวทางป้องกันและแก้ไข Error ที่พบบ่อย

1. Gitea คืออะไร

Gitea คือระบบจัดการโค้ดผ่าน Git แบบโฮสต์เอง (Self-hosted Git service) ที่มีขนาดเล็ก น้ำหนักเบา และกินทรัพยากรเครื่องน้อยมาก มีฟังก์ชันการทำงานคล้ายกับ GitHub หรือ GitLab เหมาะสำหรับนำมาติดตั้งบนเซิร์ฟเวอร์ส่วนตัวหรือใช้ทำโปรเจกต์กลุ่ม

  • Private Repository: พื้นที่เก็บโค้ดส่วนตัว ควบคุมสิทธิ์การเข้าถึงได้ปลอดภัย
  • Pull Request & Code Review: ระบบช่วยตรวจสอบโค้ดและคอมเมนต์ก่อนรวมเข้า Branch หลัก
  • Issue Tracking & Kanban: ระบบจัดการปัญหาและติดตามสถานะงานแบบบอร์ด
  • Lightweight: ใช้ทรัพยากร (RAM/CPU) น้อยมาก รันบนคอมพิวเตอร์ทั่วไปได้ราบรื่น

2. การแก้ไขปัญหาการติดตั้ง Gitea (ตัวกัน/แก้ Error)

ปัญหาที่ 1: เข้าเว็บไซต์พอร์ต 3000 ไม่ได้ (Connection Refused)
วิธีแก้ไข: สตาร์ทเซอร์วิสและเปิดพอร์ต Firewall 
sudo systemctl start gitea
sudo firewall-cmd --permanent --add-port=3000/tcp
sudo firewall-cmd --reload
ปัญหาที่ 2: ติดตั้งแล้วขึ้น Error Status 203/EXEC (Permission Denied)
วิธีแก้ไข: กำหนดสิทธิ์รันไฟล์และปรับ Context ของ SELinux 
sudo chmod +x /usr/local/bin/gitea
sudo restorecon -v /usr/local/bin/gitea
sudo systemctl daemon-reload
sudo systemctl restart gitea

3. ขั้นตอนการติดตั้ง Gitea (Step-by-Step)

ขั้นที่ 1: ติดตั้ง Git และเครื่องมือที่จำเป็น

sudo dnf install nano -y
sudo dnf update -y
sudo dnf install -y git wget ca-certificates
git --version

ขั้นที่ 2: สร้าง User สำหรับ Gitea

sudo groupadd --system git
sudo useradd \
--system \
--shell /bin/bash \
--comment "Git Version Control" \
--gid git \
--home-dir /home/git \
--create-home \
git
id git

ขั้นที่ 3: สร้างโฟลเดอร์สำหรับ Gitea

sudo mkdir -p /var/lib/gitea/{custom,data,log}
sudo chown -R git:git /var/lib/gitea
sudo chmod -R 750 /var/lib/gitea
sudo mkdir -p /etc/gitea
sudo chown root:git /etc/gitea
sudo chmod 770 /etc/gitea

ขั้นที่ 4: ดาวน์โหลด Gitea

cd /tmp
wget -O gitea https://dl.gitea.com/gitea/1.27.3/gitea-1.27.3-linux-amd64
chmod +x gitea
sudo mv gitea /usr/local/bin/gitea
gitea --version

ขั้นที่ 5: สร้าง Service ให้ Gitea (Systemd)

สร้างไฟล์ Service:

sudo nano /etc/systemd/system/gitea.service

นำค่าคอนฟิกนี้ใส่ลงไปในไฟล์:

[Unit]
Description=Gitea
After=network.target

[Service]
RestartSec=2s
Type=simple
User=git
Group=git
WorkingDirectory=/var/lib/gitea
ExecStart=/usr/local/bin/gitea web --config /etc/gitea/app.ini
Restart=always
Environment=USER=git
Environment=HOME=/home/git
Environment=GITEA_WORK_DIR=/var/lib/gitea

[Install]
WantedBy=multi-user.target

ขั้นที่ 6: เปิดใช้งาน Service

sudo systemctl daemon-reload
sudo systemctl enable --now gitea
sudo systemctl status gitea

ขั้นที่ 7: เปิด Firewall Port 3000

sudo firewall-cmd --permanent --add-port=3000/tcp
sudo firewall-cmd --reload
sudo firewall-cmd --list-ports

ขั้นที่ 8 & 9: เข้าเว็บ Gitea และตั้งค่าเบื้องต้น

เปิดเบราว์เซอร์แล้วเข้าสู่: http://<IP_Address_เครื่อง_AlmaLinux>:3000

  • Database Type: เลือก SQLite3 (สะดวกรวดเร็ว ไม่ต้องตั้งค่าพอร์ต 5432 หรือรหัสผ่านเพิ่มเติม)
  • Path: /var/lib/gitea/data/gitea.db
  • คลิกปุ่ม "Install Gitea" เพื่อสิ้นสุดการติดตั้ง

4. คำสั่ง Git พื้นฐานสำหรับใช้งานร่วมกับ Gitea

หลังจากสร้าง Repository บนเว็บ Gitea สำเร็จแล้ว ให้รันคำสั่งเหล่านี้ใน Terminal:

# 1. สร้างไฟล์และคอมมิตแรก
mkdir test
cd test
touch README.md
git init
git checkout -b main
git add README.md
git commit -m "first commit"
git remote add origin http://192.168.1.115:3000/kittikoon/kittikoon.git 
git push -u origin main
